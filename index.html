Notes

  • C1 is the direct read of your reference: continuous motion, size as a function of position, one baseline, editorial negative space. It uses the vertical (2:3-ish) asset; the others use the horizontal one.
  • C2 and C3 make the content itself the navigation. C2 uses the title art as the window; C3 uses time as the axis. Both shift the work from layout to motion.
  • C4 lets each content type look different: the board re-flows per title, with the one short line set big in its own tile.
  • 02 is the least-change option. It uses the template's existing peek geometry, so it's the baseline to compare everything else against.
  • 06 is a behavior, not just a transition. The live takeover can sit on top of 01, 02 or 03, which makes it worth testing as a separate variable (e.g. takeover on vs off).
  • C1 / C5 performance: both are transform-only per frame. C2 animates mask geometry (expensive on low-end TV GPUs), so it's a good candidate for a pre-rendered video transition in production.
  • 05 needs layered art (bg / mid / fg cut-outs). That's beyond one horizontal asset per title, so with flat key art or video it reduces to a bg + text push.
  • Live dwell is longer where it matters: 12s in 01, 18s in 06. Other slides dwell 8s.
  • Performance: everything animates opacity, transform or clip-path, except 06, which animates box geometry for prototyping speed. Production should scale a video surface with transforms. Backdrop blur (07, score bug) may need a solid fallback on low-end Tizen / webOS.
  • One design system: nav, badges, meta row, buttons, tiles and radii all come from shared/base.css, measured from the FOX One home template. Metadata is kept minimal: title art, one meta row with Live or New Episode badges, one short line and the CTAs.
  • D-pad model (every concept): focus starts on Watch. ← → move across Watch, + and bell; → past the last button pages to the next title (← past the first pages back). ↑ always goes to the nav, ↓ always goes to the Live Lineup row below the hero. Auto-advance holds for 8s after any press. C7's hero is a tile row, so ← → move along it and OK plays.
  • Up next: every concept shows a peek of the next title (neighbouring posters or cards, or an Up-next tile whose bar fills with the dwell). No dots or page numbers.
